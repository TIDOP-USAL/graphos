Tools

What each tool does and its console command, when one is available.

Home  |  Workflow  |  Tools  |  Interface  |  Command line

Tools become available according to the current project state. Processing operations are mainly under Workflow; utilities and viewers are under Tools.

Projects and images

Projects

Create, open, save, save as and close projects; recent projects provide quick access to previous work. The project file stores settings and references to generated products. When using “Save as”, keep referenced data accessible and check its paths.

Console: createproj creates a project; see createproj. Opening, saving and closing from the interface have no dedicated command.

Add images and extract video frames

Add photographs to a project and associate available camera data. The video tool extracts images from a video file; review the selected frames and extraction interval to avoid redundant images.

Console: image_manager adds or removes project images. Video-frame extraction has no registered command.

Cameras and calibration import

Manage cameras associated with project images, review their parameters, and import or export calibrations in supported formats. Incorrect calibration affects orientation, dense reconstruction and orthorectification. External camera import is available as a project import action.

Console: cameras lists cameras and manages calibration; see cameras. The separate project camera-import action has no dedicated command.

Reconstruction

Feature extraction and matching

SIFT extraction detects points and descriptors. Matching links those observations across images and prepares data for orientation. The feature viewer displays detected points; the match viewer inspects image pairs and calculated matches.

Console: featextract and featmatch. See featextract and featmatch.

Orientation

Estimate camera poses and a sparse reconstruction using sequential or global orientation. Absolute orientation can use GCPs or camera positions, including an option to use RTK accuracy. Calibration can be held fixed. Quality depends on match coverage and available control.

Console: ori. See ori.

Undistort images

Creates rectified images using camera calibration. This can prepare imagery for products that require distortion-corrected input.

Console: undistort. See undistort.

Ground control points and scale

Import GCPs to constrain or georeference the orientation. Check that their coordinates and file CRS match the project. The scale tool provides a known-distance reference to scale a reconstruction without full georeferencing.

Console: gcps imports GCPs. The scale tool has no dedicated command.

Models and mapping

Dense point cloud

Computes depth and fuses observations into a dense point cloud. Available methods are MVS, PMVS and SMVS; their parameters trade detail and coverage against processing time and memory. CUDA acceleration depends on hardware, drivers and build options.

Console: dense. See dense.

DSM and DTM

Generates digital surface models (DSM) and/or digital terrain models (DTM) from dense data. Set the ground sample distance (GSD) and output CRS. A DSM represents observed surfaces; a DTM represents terrain filtered by the processing method.

Console: dem. See dem.

3D mesh

Reconstructs a triangular surface from the dense cloud. Depth and boundary conditions affect surface detail and closure. Mesh reconstruction and mesh export are separate actions.

Console: mesh reconstructs the mesh; mesh export is available in the interface and has no dedicated command.

Orthomosaic

Combines rectified images into an orthorectified image. Configure GSD, CRS, interpolation and mosaic method. Availability and output quality depend on orientation, surface data and image coverage.

Console: ortho. See ortho.

Inspection, export and settings

2D and 3D viewers

The image viewer displays project photographs; feature and match viewers display photogrammetric observations. The 3D viewer inspects clouds and models, changes view direction and adjusts rendering. Viewers do not change reconstructed data by themselves.

Export results

Export point clouds with available colors and normals, camera poses in supported formats, and meshes through the interface. Check the CRS, format and units before sharing files.

Console: export_point_cloud and export_camera_poses. Mesh export has no registered command.

Coordinate reference system

Review or select the CRS associated with the project and its products. Do not mix coordinate systems: check units, zone and datum for images, GCPs and outputs.

Settings and properties

Settings customize application and viewer options, including the language. Restart GRAPHOS for a language change to take effect. The properties panel summarizes project metadata and selected items.
