Photogrammetric processing

Workflow

From photographs to 3D and mapping products.

1. Create a project and add images

Create a new project or open its project file. Add photographs from the workflow; you can also extract images from a video. Keep the source images available during processing and avoid moving them after they have been added.

Sufficient overlap and varied camera geometry usually produce a more reliable reconstruction. Check that camera data and initial parameters are reasonable; see Cameras.

2. Extract features

Feature extraction detects distinctive points in each photograph and computes their descriptors. GRAPHOS uses SIFT; processing can use the CPU or CUDA when available and enabled. Tune maximum image size and feature count to suit the required detail and available resources.

This step prepares data for matching. If there are too few features or poor coverage, check image resolution, focus and contrast before continuing.

Command: featextract. See its reference or run graphos.exe featextract --help.

Feature extraction tool.

3. Match features

Matching finds common points between image pairs and filters inconsistent matches. The result identifies connected images and provides observations for orientation.

Inspect pairs and matches if reconstruction fails or leaves images unoriented. Weak coverage may be caused by limited overlap, lighting changes or textureless surfaces.

Command: featmatch. See its reference or run graphos.exe featmatch --help.

Image pairs and matches.

4. Estimate orientation

Orientation estimates camera positions and rotations and reconstructs a sparse model. GRAPHOS provides sequential and global methods. Relative orientation does not require control coordinates; for georeferencing, enable absolute orientation and provide ground control points (GCPs) or compatible camera positions.

Fix calibration to keep internal camera parameters constant. If RTK positions are used, their accuracy can also be enabled. Review the oriented-image percentage, errors and control-point distribution before accepting the result.

Command: ori. See its reference or run graphos.exe ori --help.

Orientation settings and sparse model.

5. Generate products

Once cameras are oriented, generate a dense point cloud using MVS, PMVS or SMVS. From the dense cloud, create a DSM and/or DTM, reconstruct a mesh and generate an orthomosaic. These products require valid input from earlier stages.

  • Dense cloud: dense; choose the method and suitable parameters.
  • DSM/DTM: dem; set the pixel size and coordinate reference system (CRS).
  • Mesh: mesh; reconstructs a surface from the dense cloud.
  • Orthomosaic: ortho; creates an orthorectified image using orientation and available surface data.

Read the descriptions and prerequisites in Tools and the console reference in Command line.

6. Review and export

Use the 2D and 3D viewers to inspect images, points, matches and reconstructed geometry. Save the project and export the point cloud, camera poses or mesh for downstream use.

Parameter names and accepted values may depend on the version and build options. The command's own help is the authoritative reference for the installed build.
