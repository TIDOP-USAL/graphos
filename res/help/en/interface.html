The main window groups the menu bar, toolbars, project tree, workspace and information panels. The exact layout can vary with window size and visible panels.

Project tree

The tree organizes project items such as images, cameras, match pairs and results. Select an item to inspect its properties or open it in a viewer. Actions are enabled when their required input data is available.

Workspace and viewers

The workspace displays images and 3D results. Use viewer controls to change the view, zoom and adjust visible layers. Feature and match panels help diagnose coverage or alignment problems.

Processes and messages

When an operation starts, GRAPHOS displays progress and temporarily disables parameters that cannot be changed during processing. If supported, cancel it using the progress control. Review warnings and errors before trying again.

Save the project after processing and before closing GRAPHOS to preserve settings and references to results.
