Console reference

Command line

Run GRAPHOS operations from a console using the same projects as the graphical interface.

Home  |  Workflow  |  Tools  |  Interface  |  Command line

Basic usage

Open a console in the folder containing the GRAPHOS executable or use its full path. On Windows, the project executable is graphos.exe. To list general commands and inspect a command's syntax:

graphos.exe --help
graphos.exe <command> --help
graphos.exe dense --help

Processing commands commonly take the project XML file with -p or --prj. Quote paths that contain spaces. For example:

graphos.exe featextract -p "D:\projects\building\building.xml"
graphos.exe dense -p "D:\projects\building\building.xml" --method mvs

Important: always check --help for all arguments, accepted values, defaults and options available in your build. CUDA options depend on the hardware and how GRAPHOS was built.

Full help for selected commands

createproj — Create a project

Creates a GRAPHOS project. A name without an absolute path is placed in the default projects folder. The name can also be the path to a project XML file.

graphos.exe createproj [-h | --help] [--version] [--license]
                       -n <name-or-file.xml>
                       [-d <description>] [-o]
OptionRequirementDescription
-n, --nameRequiredProject name or project file path (.xml).
-d, --descriptionOptionalProject description.
-o, --overwriteOptionalForce overwrite of an existing project. Default: false.
graphos.exe createproj --name "building" --description "Photogrammetric survey"

image_manager — Manage images

Adds one image or a list of images to a project; with --delete, removes the specified image or images. The default camera type is OpenCV 1 and the default progress display is COLOR.

graphos.exe image_manager [-h | --help] [--version] [--license]
                          -p <project.xml>
                          [-i <image>] [-l <image-list>]
                          [-c <camera-type>] [-d]
                          [--progress_bar <type>]
OptionRequirementDescription
-p, --prjRequiredPath to the project file.
-i, --imageOptionalPath to an image to add or, with --delete, remove from the project.
-l, --image_listOptionalFile containing a list of images to add or, with --delete, remove from the project.
-c, --cameraOptionalCamera type: Pinhole 1, Pinhole 2, Radial 1, Radial 2, OpenCV 1, OpenCV Fisheye, OpenCV 2, Radial Fisheye 1, Radial Fisheye 2 or Radial 3. Default: OpenCV 1.
-d, --deleteOptionalRemove the specified image or list from the project. Without this option, images are added.
--progress_barOptionalProgress style: NORMAL, COLOR, PERCENT, SPINNER or DISABLE. Default: COLOR.
graphos.exe image_manager -p "D:\projects\building\building.xml" -i "D:\photos\img001.jpg" --camera "OpenCV 1"
graphos.exe image_manager -p "D:\projects\building\building.xml" --image_list "D:\photos\images.txt"
graphos.exe image_manager -p "D:\projects\building\building.xml" -i "D:\photos\img001.jpg" --delete

featextract — Extract features

Runs SIFT feature detection and computes descriptors. Adjust the maximum image size and SIFT parameters to suit the image detail and available resources. CUDA is used unless disabled and available in the build.

graphos.exe featextract [-h | --help] [--version] [--license]
                        -p <project.xml>
                        [-s <maximum-size>]
                        [--max_features_number <number>]
                        [--octave_resolution <layers>]
                        [--contrast_threshold <threshold>]
                        [--edge_threshold <threshold>]
                        [--progress_bar <type>] [--disable_cuda]
OptionRequirementDescription
-p, --prjRequiredPath to the project file.
-s, --max_image_sizeOptionalMaximum image size used for extraction. Default: 3200.
--max_features_numberOptionalMaximum number of features to detect. Default: 5000.
--octave_resolutionOptionalSIFT number of layers per octave. Default: 3.
--contrast_thresholdOptionalSIFT contrast threshold. Default: 0.006667.
--edge_thresholdOptionalSIFT edge threshold used to filter out edge-like features. Default: 10.000000.
--progress_barOptionalProgress bar type: NORMAL, COLOR, PERCENT, SPINNER or DISABLE.
--disable_cudaOptionalDisables CUDA acceleration. Default: false.
graphos.exe featextract -p "D:\projects\building\building.xml"
graphos.exe featextract -p "D:\projects\building\building.xml" --max_features_number 8000 --disable_cuda

featmatch — Match features

Computes matches between project images. The thresholds control match selection and geometric tolerance; exhaustive matching and cross-checking change the matching strategy.

graphos.exe featmatch [-h | --help] [--version] [--license]
                      -p <project.xml>
                      [-r <threshold>] [-d <threshold>] [-e <error>]
                      [-c <confidence>] [-x]
                      [--exhaustive_matching] [--progress_bar <type>]
                      [--disable_cuda]
OptionRequirementDescription
-p, --prjRequiredPath to the project file.
-r, --ratioOptionalLowe's ratio threshold. Default: 0.800000.
-d, --distanceOptionalDistance threshold. Default: 0.700000.
-e, --max_errorOptionalMaximum reprojection error. Default: 4.000000.
-c, --confidenceOptionalConfidence level.
-x, --cross_checkOptionalEnables cross-checking. Default: true.
--exhaustive_matchingOptionalUses exhaustive matching. Default: false.
--progress_barOptionalProgress bar type: NORMAL, COLOR, PERCENT, SPINNER or DISABLE.
--disable_cudaOptionalDisables CUDA acceleration. Default: false.
graphos.exe featmatch -p "D:\projects\building\building.xml"
graphos.exe featmatch -p "D:\projects\building\building.xml" --exhaustive_matching --disable_cuda

ori — Orient images

Estimates sequential or global image orientation. Absolute orientation can use ground control points (GCPs) or camera poses; RTK positioning accuracy can also be used.

graphos.exe ori [-h | --help] [--version] [--license]
                -p <project.xml> [-m <sequential|global>]
                [-c] [--use_gcp] [--use_poses]
                [--use_rtk_accuracy] [-a]
OptionRequirementDescription
-p, --prjRequiredProject file.
-m, --methodOptionalOrientation method: sequential or global.
-c, --fix_calibrationOptionalFixes calibration during orientation.
--use_gcpOptionalUses Ground Control Points for absolute orientation.
--use_posesOptionalUses the camera poses file for absolute orientation.
--use_rtk_accuracyOptionalUses RTK positioning accuracy.
-a, --absolute_orientationOptionalEnables absolute orientation.
graphos.exe ori -p "D:\projects\building\building.xml" --method sequential
graphos.exe ori -p "D:\projects\building\building.xml" --absolute_orientation --use_gcp

dense — Create a dense point cloud

Generates a dense point cloud using the selected method. Each method has its own options: MVS configures resolution and view fusion, PMVS controls clustering and filtering, and SMVS provides scale and smoothing controls.

graphos.exe dense [-h | --help] [--version] [--license]
                  -p <project.xml> [-m <mvs|pmvs|smvs>]
                  [method-specific options]
                  [-s] [--disable_cuda]
OptionRequirementDescription
-p, --prjRequiredProject file.
-m, --methodOptionalDensification method: mvs, pmvs or smvs.
--mvs:resolution_levelOptionalResolution level.
--mvs:min_resolutionOptionalMinimum resolution.
--mvs:max_resolutionOptionalMaximum resolution.
--mvs:number_viewsOptionalNumber of views.
--mvs:number_views_fuseOptionalNumber of views to fuse.
--mvs:estimate_colorsOptionalEstimates color. Default: true.
--mvs:estimate_normalsOptionalEstimates normals. Default: true.
--pmvs:visibilityOptionalUses visibility information. Default: true.
--pmvs:images_per_clusterOptionalImages per cluster. Default: 100.
--pmvs:levelOptionalLevel. Default: 1.
--pmvs:cell_sizeOptionalCell size. Default: 2.
--pmvs:thresholdOptionalThreshold. Default: 0.7.
--pmvs:window_sizeOptionalWindow size. Default: 7.
--pmvs:minimun_imagesOptionalMinimum number of images. Default: 3.
--pmvs:original_depthOptionalUses original image depth. Default: false.
--smvs:input_image_scaleOptionalInput image scale. Default: 1.
--smvs:output_depth_scaleOptionalOutput depth scale. Default: 2.
--smvs:shading_optimizationOptionalUses shading-based optimization. Default: false.
--smvs:sgmOptionalUses semi-global matching. Default: true.
--smvs:smooth_factorOptionalSurface smoothing factor. Default: 1.0.
-s, --segmentOptionalEnables automatic segmentation. Default: false.
--disable_cudaOptionalDisables CUDA.
graphos.exe dense -p "D:\projects\building\building.xml" --method mvs
graphos.exe dense -p "D:\projects\building\building.xml" --method pmvs --pmvs:level 1

mesh — Reconstruct a mesh (Poisson)

Reconstructs a mesh using the Poisson method. Depth controls the maximum reconstruction depth; the boundary type specifies the condition applied at the boundary.

graphos.exe mesh [-h | --help] [--version] [--license]
                 -p <project.xml> [--depth <depth>]
                 [--boundary_type <Free|Dirichlet|Neumann>]
OptionRequirementDescription
-p, --prjRequiredProject file.
--depthOptionalMaximum reconstruction depth.
--boundary_typeOptionalBoundary type: Free, Dirichlet or Neumann.
graphos.exe mesh -p "D:\projects\building\building.xml" --depth 10 --boundary_type Free

dem — Create a DSM and/or DTM

Generates a digital surface model (DSM), a digital terrain model (DTM), or both. GSD sets the output pixel size, and CRS specifies its coordinate reference system.

graphos.exe dem [-h | --help] [--version] [--license]
                -p <project.xml> [-g <gsd>]
                [--dsm] [--dtm] [--crs <crs>]
OptionRequirementDescription
-p, --prjRequiredProject file.
-g, --gsdOptionalGround sample distance (output pixel size).
--dsmOptionalCreates a Digital Surface Model.
--dtmOptionalCreates a Digital Terrain Model.
--crsOptionalCoordinate Reference System.
graphos.exe dem -p "D:\projects\building\building.xml" --dsm --dtm --gsd 0.05

ortho — Create an orthophoto

Creates an orthophoto from oriented images and available surface products. Configure its GSD, CRS, interpolation and mosaic method.

                  -p <project.xml> [-g <gsd>] [--crs <crs>]
                  [-i <NEAREST|BILINEAR|BICUBIC>]
                  [-m <RLB|SBB>] [--disable_cuda]
OptionRequirementDescription
-p, --prjRequiredProject file.
-g, --gsdOptionalGround sample distance (output pixel size).
--crsOptionalCoordinate Reference System.
-i, --interpolationOptionalInterpolation: NEAREST, BILINEAR or BICUBIC.
-m, --mosaic_methodOptionalMosaic method: RLB or SBB.
--disable_cudaOptionalDisables CUDA. Default: false.
graphos.exe ortho -p "D:\projects\building\building.xml" --gsd 0.05 --interpolation BICUBIC --mosaic_method SBB

cameras — Manage cameras

Lists project cameras, displays camera information or imports/exports a calibration file. Specify a camera ID to inspect or exchange calibration data.

graphos.exe cameras [-h | --help] [--version] [--license]
graphos.exe cameras -p <project.xml> --list
graphos.exe cameras -p <project.xml> --camera_id <id>
graphos.exe cameras -p <project.xml> --camera_id <id> --export_calib <file> [-f <format>]
graphos.exe cameras -p <project.xml> --camera_id <id> --import_calib <file> [-f <format>]
OptionRequirementDescription
-p, --prjRequiredPath to the project file.
-l, --listOptionalList project cameras.
-c, --camera_idOptionalShow information for the camera with the specified ID.
--export_calibOptionalDestination file for the exported calibration.
--import_calibOptionalCalibration file to import.
-f, --formatOptionalCalibration format: OpenCV, Pix4D, Agisoft or ODM.
graphos.exe cameras -p "D:\projects\building\building.xml" --list
graphos.exe cameras -p "D:\projects\building\building.xml" --camera_id 1
graphos.exe cameras -p "D:\projects\building\building.xml" --camera_id 1 --export_calib "calibration.xml" --format OpenCV
graphos.exe cameras -p "D:\projects\building\building.xml" --camera_id 1 --import_calib "calibration.xml" --format Agisoft

export_camera_poses — Export camera poses

Exports camera orientations from the project. Available formats are text (TXT) and ODM (ODM), with ODM written as JSON. The quaternion option applies to text output only.

graphos.exe export_camera_poses [-h | --help] [--version] [--license]
                                -p <project.xml> --file <output>
                                [-f TXT | ODM] [-q]
OptionRequirementDescription
-p, --prjRequiredPath to the project file.
--fileRequiredOutput file: text .txt or ODM .json.
-f, --formatOptionalExport format: TXT or ODM. Default: TXT.
-q, --quaternionsOptionalWrite rotations as quaternions; text format only. Default: disabled.
graphos.exe export_camera_poses -p "D:\projects\building\building.xml" --file "poses.txt" --format TXT --quaternions
graphos.exe export_camera_poses -p "D:\projects\building\building.xml" --file "poses.json" --format ODM

Interface-only tools

In this version, these actions have no dedicated console command: extracting images from video, the separate camera-import action, setting the scale, opening viewers, changing the project CRS through its panel, exporting a mesh and managing preferences. Opening, saving and closing projects are also interface actions.

Automation

Run each operation on a saved project and retain console output and log files for troubleshooting. Check the process exit code before starting the next stage. Do not run concurrent operations that write to the same project or derived data.
